## Segundo Avance del proyecto integrador de POO
### Ejecutar el programa en Windows
Para poder compilar y ejecutar este avance del proyecto en la terminal (PowerShell) debemos hacer lo siguiente:
1. Clonar el repositorio desde GitHub ejecutando el comando `git clone https://github.com/GrakoRocko/Proyecto-POO.git`
2. Ubicarse en la carpeta raíz del proyecto descargado
3. Compilar el código ejecutando el comando `javac app/*.java modelo/*.java servicio/*.java`
4. Ejecutar el programa con el comando `java app.Main`

### Ejecutar el programa en Mac y Linux
Para probar el proyecto en la Terminal de sistemas basados en Unix los pasos son los mismos:
1. Clonar el repositorio desde GitHub ejecutando el comando `git clone https://github.com/GrakoRocko/Proyecto-POO.git`
2. Ubicarse en la carpeta raíz del proyecto descargado
3. Compilar el código ejecutando el comando `javac app/*.java modelo/*.java servicio/*.java`
4. Ejecutar el programa con el comando `java app.Main`
> **Nota:** Debido a que el programa es estático el resultado siempre será el mismo en cada ejecución.
